# Kouhu Elementary School — English Lives Here

An interactive 16:9 keynote-style presentation built as a static website.

## Controls

- Left / right arrows or space to navigate
- `M` for the chapter index
- `F` for fullscreen
- Swipe on touchscreens

The imagery in this prototype comes from public, school-owned posts and the school's current public Maps listing. Replace the video placeholder with the school's approved local MP4 before the final event build.
